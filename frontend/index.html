Why is my file secure?

• Ciphertext Storage: Your file is encrypted with a unique 256-bit key before storage. The server stores ciphertext rather than original file data.

• Unique File Keys: Every file transfer derives an independent symmetric key and an ephemeral keypair.

• Automatic Expiration: Shared links expire automatically based on your time and download limits.

• Constant-Time Integrity: Poly1305 AEAD tags immediately reject altered or corrupted files.
